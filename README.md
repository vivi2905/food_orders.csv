#Food Order Value Prediction 
#

#Deskripsi Proyek

Proyek ini merupakan analisis data dan penerapan Machine Learning pada dataset pemesanan makanan di New Delhi. Proyek ini bertujuan untuk memahami karakteristik data, melakukan Exploratory Data Analysis (EDA), serta membangun model regresi untuk memprediksi Order Value.Proses analisis dan pemodelan dilakukan menggunakan Python melalui Jupyter Notebook.
#
#Tujuan Proyek

Memahami karakteristik dataset pemesanan makanan.
Melakukan pembersihan dan preprocessing data.
Mengeksplorasi distribusi data dan korelasi antarvariabel.
Membangun model Machine Learning untuk memprediksi nilai pesanan.
Membandingkan performa beberapa algoritma regresi.
#
#Teknologi yang Digunakan

Python,Pandas,Scikit-learn,Matplotlib,Seaborn,Jupyter Notebook,Joblib,Pickle
